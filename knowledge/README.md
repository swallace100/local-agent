# Knowledge folder

Put your notes and documents here, then run `agent index`. The agent searches them with `knowledge_search`.

- Supported files: `.md`, `.txt`, `.rst`, `.py`, `.js`, `.ts`, `.json`, `.yaml`, `.yml`, `.toml`, `.html`, `.csv`
- Everything here except this README is ignored by git, so it won't reach your public repo.
- Don't put passwords or API keys here. See the Safety section of the main README.
